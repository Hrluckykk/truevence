Why verify PAN?

Prevent financial fraud

Expose fake PANs before they enter payroll or vendor systems.

Duplicate & fake detection

Flag multiple PANs or forged numbers that indicate identity manipulation.

How PAN verification works

1. Candidate consent

Written permission is obtained before accessing any PAN-related data.

2. Verification run

Manual inspection or instant API call validates PAN against Income Tax database.

3. Detailed report

An audit‑ready report shows the match status, name, and any discrepancies.

Manual Verification

Our verification officers conduct a thorough physical inspection of the original PAN card, looking for:

  • Correct hologram and lamination quality
  • Consistency of the PAN number format (5 letters, 4 digits, 1 letter)
  • Photograph and signature match with the candidate's other documents
  • Cross‑reference with the Income Tax Department's database via official channels

Manual verification is ideal for roles where physical document inspection is necessary or when API access is intermittent.

API‑based Verification

For high‑volume, digital‑first organisations, our API integration connects directly to the Income Tax PAN verification service:

  • Real‑time validation of PAN number, name, and date of birth
  • Instant response with match/mismatch status and masked data
  • End‑to‑end encryption and zero storage of sensitive information
  • Seamless integration with your HRMS, payroll, or vendor onboarding platforms

API checks are completed in under a second, enabling bulk verification for mass hiring campaigns.

Manual vs. API at a glance

Manual

  • Physical inspection of original card
  • Officer verifies security features
  • Best for low volumes or field roles
  • Not instant (depends on logistics)

API

  • Real‑time Income Tax DB match
  • Instant result, no manual delay
  • Bulk processing friendly
  • Needs stable integration & consent
