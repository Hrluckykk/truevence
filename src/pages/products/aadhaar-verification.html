How Aadhaar verification works

1. Candidate consent

We collect explicit, documented consent before any check begins.

2. Verification run

Manual inspection or API call validates the Aadhaar against UIDAI records.

3. Detailed report

You receive an audit‑ready report highlighting match status and any flags.

Manual Verification

Our trained officers physically inspect the original Aadhaar card, checking for:

  • Aadhaar logo, microtext, and ghost image security features
  • Photograph and demographic match with candidate documents
  • UIDAI-format number cross‑reference
  • Signed consent and audit-ready scanned copies

Ideal for roles requiring physical document verification or limited API access.

API‑based Verification

For tech-driven, high‑volume environments, our API integration delivers instant results:

  • Real‑time demographic authentication (name, DOB, gender)
  • Biometric‑lite options to reduce drop‑off
  • End‑to‑end encryption, zero biometric storage
  • Seamless integration with your HRMS / onboarding flow

Bulk verification in seconds, with full audit logs.

Manual vs. API at a glance

Manual

  • Physical inspection of original document
  • Officer verifies security features
  • Best for low volumes or field roles
  • Not instant (TAT depends on logistics)

API

  • Real‑time UIDAI demographic match
  • Instant result, digital‑first
  • Scales to thousands of checks
  • Requires stable API integration & consent

Security & data protection

Consent‑first approach

Documented candidate consent is mandatory before any verification. Never without permission.

Zero biometric storage

Core biometric data is never stored or logged. We only process demographic match responses.

Encryption at rest & in transit

All data transfers use TLS 1.3, and stored records are AES‑256 encrypted.

Audit‑ready compliance

All verifications are logged with timestamps and consent proofs for regulatory audits.
